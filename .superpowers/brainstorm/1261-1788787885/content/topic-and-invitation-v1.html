官方赛事与项目

发现赛事 → 简介 / 资料 / 时间安排 → 招募列表 → 临时沟通 → 双方确认组队

一个赛事的一届对应一个公共话题。个人赛可以只有信息和原站报名入口，不强制开组队区。

认证组织活动

发现活动 → 活动详情 → 按活动要求报名或进入组队区

讲座按人报名，团队赛可组队。发布者需要该组织的明确授权。

校园搭子

发现具体邀约 → 时间 / 地点 / 人数 → 申请沟通 → 双方确认

“今天打羽毛球”直接是一条邀约，不需要先创建“羽毛球话题”。羽毛球属于聚合标签。

保留原始来源链接、发布者、原文时间、核验时间与变更记录。同一赛事的新闻、报名通知、规则附件并入同一届话题；不同届次独立保留。已审核来源之后可逐步增加受控的自动更新。

标签、认证与业务字段分开管理

可信来源 / 组织身份
由平台核验的身份和来源属性，不是用户或 AI 随意添加的标签。“官网收录”不等于学校为平台背书。
赛事级别
国家级、校级等，需要来源依据；学院或书院名称另存组织归属，不能仅凭主办单位推断赛事级别。
活动主题
数学建模、羽毛球、程序设计等使用标准 tag_id；“羽球”只解析为已有的“羽毛球”，不创建新标签。
地点 / 时间 / 人数
使用可检索的结构化字段。已满、已截止等是由状态和时间计算出的业务信息，不建成随意文本标签。
组队帖关联
比赛招募必须有 topic_id；日常邀约使用独立类型 invitation，不要求 topic_id。
