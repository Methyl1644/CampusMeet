## 前置准备

- [ ] PostgreSQL 已启动，`campusmate` 库已建
- [ ] `.env` 已填 `DATABASE_URL` 和 `JWT_SECRET`
- [ ] 后端：`python src/main.py -m http -p 3000` 能启动，日志无报错
- [ ] 演示数据：`python scripts/seed.py` 已执行
- [ ] 前端：`cd apps/web && npm install && npm run dev` 能启动
- [ ] 浏览器打开 `http://localhost:5173` 能看到登录页
