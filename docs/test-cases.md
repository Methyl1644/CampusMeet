## 2. 用户注册与认证

### TC-AUTH-04：未认证用户尝试申请

## 3. AI 对话式发帖

### TC-POST-01：一句话生成草稿
| 项目 | 内容 |
|------|------|
| 前置条件 | 已登录且已认证 |
| 操作步骤 | 1. 进入发布页 2. 输入"我想参加美赛，还缺两个队友，一个会编程一个英语好" 3. 等待AI响应 |
| 预期结果 | AI 返回追问问题 + 结构化草稿（活动名=数学建模竞赛，目标人数=3，需要角色=[编程,英文写作]） |
| 优先级 | P0 |

### TC-POST-02：AI 追问缺失信息
| 项目 | 内容 |
|------|------|
| 前置条件 | 已在发布页，AI已返回首轮草稿 |
| 操作步骤 | 查看AI返回的追问问题 |
| 预期结果 | 追问内容至少包含：参赛年份、每周投入时间 |
| 优先级 | P0 |

### TC-POST-03：回答追问后草稿更新
| 项目 | 内容 |
|------|------|
| 前置条件 | AI已返回追问 |
| 操作步骤 | 回答"2026年美赛，每周10小时" |
| 预期结果 | 草稿中 weekly_hours 更新为"10h/周" |
| 优先级 | P0 |

### TC-POST-04：手动编辑草稿字段
| 项目 | 内容 |
|------|------|
| 前置条件 | 草稿已生成 |
| 操作步骤 | 直接修改草稿中"目标人数"从3改为4 |
| 预期结果 | 草稿字段更新成功 |
| 优先级 | P0 |

### TC-POST-05：跳过追问直接发布
| 项目 | 内容 |
|------|------|
| 前置条件 | AI已返回首轮草稿和追问 |
| 操作步骤 | 不回答追问，直接点击"确认发布" |
| 预期结果 | 发布成功，缺失字段标注"待确认" |
| 优先级 | P0 |

### TC-POST-06：AI 调用失败降级
| 项目 | 内容 |
|------|------|
| 前置条件 | 模拟AI服务不可用 |

## 12. AI 评测数据集（角色D配合）
